Architecture Decision Records

Document version: 0.2.0 · Applies to SpecGen 0.2.0

ADRs capture significant decisions that would otherwise disappear as the working design changes.

Statuses: proposed, accepted, deprecated, superseded.

Accepted ADR content is not rewritten to make history look cleaner. A later decision supersedes it and links both records. Typographical corrections are allowed.

  • ADR-0001 — Canonical IR and projections
  • ADR-0002 — Agent-Workflow is a versioned target, not a dependency
  • ADR-0003 — Version machine contracts from inception
  • ADR-0004 — Significant decisions use ADRs

  • ADR-0005 — Authoring history uses events, immutable snapshots, and derived deltas

  • ADR-0006 — Authoring modes are policy profiles; Agent-Workflow is an opinionated profile

  • ADR-0007 — Brownfield analysis is evidence-first and read-only

  • ADR-0008 — Agent-assisted brownfield analysis stays separate and optional
