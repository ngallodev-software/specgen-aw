# Architecture Decision Records

> Document version: 0.1.8 · Applies to SpecGen 0.1.8

ADRs capture significant decisions that would otherwise disappear as the working design changes.

Statuses: `proposed`, `accepted`, `deprecated`, `superseded`.

Accepted ADR content is not rewritten to make history look cleaner. A later decision supersedes it and links both records. Typographical corrections are allowed.
